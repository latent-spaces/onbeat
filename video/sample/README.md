# The included sample

An 11.52-second excerpt from **Allow Always**, with the project's original robot atlas. No keys, generation or alignment are needed.

Run `make sample` at the repo root. It builds these audio/timing/config inputs through `video/template/` and writes `out/sample.mp4`. Change `reel.json` to make the first remix: try another title, palette or cast phase.

`timing.json` keeps the measured beat grid and curated sung-word timing from the original chorus. The partial phrase at the excerpt’s end is omitted from the captions. `song.mp3` is the local compressed excerpt; no third-party character artwork is used.
