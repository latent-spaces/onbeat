# Launch-channel evidence addendum

Checked 2026-11-14, approximately 09:52–09:53 UTC, by codex-tooling-2. This supplements the README audit with actual public discussion evidence. It does **not** attribute GitHub stars to a channel.

## Motion Canvas: dated Hacker News exposure and reader friction

[Hacker News discussion, 2023-02-22](https://news.ycombinator.com/item?id=34897707). The captured page shows 180 points and 35 comments. It links the GitHub repository. This verifies a dated channel appearance, not the original launch date or a founder-led submission.

Readers complained that they could not quickly find an example and instead linked an explainer. The [visual/GIF request](https://news.ycombinator.com/item?id=34902199) and [link to the author's explainer](https://news.ycombinator.com/item?id=34900161) support showing the output prominently. These are individual comments, not a representative user survey. No historical star series was joined to this event.

Implication for music-reels: give visitors an actual output and a precise tool description before asking them to install. A favorable distribution opportunity can still expose weak explanation. We cannot estimate how many stars a better demo would add.

## /brag: author-style Reddit showcase with demo and installation

[Reddit showcase post](https://www.reddit.com/r/ClaudeCode/comments/1ubrc1y/i_built_a_claude_code_skill_called_brag_that/), in r/ClaudeCode, posted by `u/shunithaviv` with a first-person claim of authorship. The reader exposed a relative age of “4mo ago”; an exact publication timestamp was not available in this capture. Identity was not independently verified.

Observed structure: a user problem, an explanation of the short-video result, a media preview, a linked demo site, install commands, a token-budget warning, a request for feedback, and a repository link. Comments include both people sharing attempts and criticism of output polish. The thread establishes that this project was showcased in that community and received public feedback; it does not establish first launch, successful conversion, or the cause of the later star acceleration.

Implication for music-reels: when public posting is separately authorized, a useful showcase can pair the real reel with its editable source, requirements and a feedback invitation. Before that, prepare a reproducible sample. Do not use this anecdote to promise reach or infer a universal best channel.
