# page-mascot: verified author announcement

Research observation: 2026-11-14. This follow-up supersedes the earlier statement in `page-mascot.md` that no dated author announcement was verified. It does **not** supply a star-growth curve.

## Primary launch trace

[Kamran Ahmed / @nilbuild on X](https://x.com/nilbuild/status/2099450737684029539) announced page-mascot at **2026-09-14 10:50:36 UTC**, according to the saved primary-post extraction. The post introduces the interactive-mascot skill, shows the `/page-mascot [your character]` invocation and explains the cursor/click behavior, then links directly to the [live demo](https://koboyo.com/page-mascot).

The repository metadata records creation at **2026-09-14 06:55:59 UTC**. Thus the observed announcement is on the same day, approximately **3 h 55 min after repository creation**. This is evidence of an author-led launch trace, not proof that it was the first announcement anywhere.

The extraction reports 2,242 likes, 179 reposts and 65 replies as observed during this research. These are post-engagement observations, not GitHub referrals or star conversions. No historical engagement curve was collected.

## What it changes in the recommendation

Copy the launch **format**: one clear behavior, one actionable command, and a direct route to a demonstrable result. For music-reels, pair a short audible/visible reel with a real command that uses the committed sample. The existing short prototype provides a result users can reproduce without new generation. Publish only when the owner approves; this research performs no posting or account actions.

Do not claim this post caused page-mascot's 1,376 observed stars. Timestamped GitHub stargazers returned 404, and there are no referral analytics or before/after star snapshots. The defensible statement is: a same-day author announcement and demo destination are verified; growth speed and attribution remain unknown.

## Evidence and bounded method

- `web/page-mascot-author-announcement.md`: Firecrawl extraction of the author's post, including timestamp and reported public metrics.
- `web/page-mascot-author-search.json`: author-name search that discovered the original post and demo destination.
- `web/page-mascot-launch-search.json`: repository-name launch search; third-party Facebook/Instagram reposts appeared, but were not date-verified and are not used to claim a launch cause.
- `web/page-mascot-hn-search.json`: a narrow Show HN search returned aggregators/roundups, not a verified original Show HN submission. This is a search limitation, not proof none exists.
- `page-mascot-metadata.json`: saved GitHub repository metadata.

The initial repository scrape verified the authenticated search setup, then three narrow searches were used. No login, sign-up, interaction, external publication or account change occurred.
